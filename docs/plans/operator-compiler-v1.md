# Operator Compiler v1 Implementation Plan

Goal: compile the 18 bigdic operator families into inspectable executable contracts and a state-conditioned controller using the measured operator-value artifacts.

Deliverables map one-to-one to the 15 extension tasks: state IR, contracts, applicability, marginal value, VOC, EVSI, conditional interactions, motifs, macro induction, planners, adaptive budget allocation, counterfactual replay, transfer evaluation, external causal evidence boundary, and runtime controller.

Hard constraints: the dictionary remains source evidence, the epistemic kernel is immutable, external model evidence is never imputed, and all generated recommendations expose their evidence basis.
