# BiggestDic

BiggestDic is the expansion mode of `bigdic`: operator ontology + executable semantics + causal experiments + model response atlas + composition algebra + operator discovery + adaptive compiler.

## Invariant

A new distinction is promoted only when it can change a required result, admissible action, measured performance, verification obligation, or closure state under a declared regime. More words without measured behavioral consequence do not count as growth.

## Current executable lanes

1. `FINITE_EXACT`: deterministic operator/value measurements already committed under `data/measurements/`.
2. `REPLAY`: deterministic provider-neutral causal fixtures used in CI.
3. `LOCAL_TRANSFORMERS`: isolated GitHub Actions CPU inference with no Hugging Face Jobs billing dependency.
4. `OPENAI_COMPATIBLE`: optional OpenRouter, Groq, and Gemini-compatible backends activated only when their API-key environment variables exist.

Hugging Face Jobs is no longer a required transport.

## Experimental unit

Every causal task supports four conditions:

- control
- matched placebo
- operator treatment
- operator treatment + answer-changing mistake check

Every result records provider, model, prompt hash, response hash, condition, output, and error state. Gold/scoring metadata is kept outside the inference request.

## Expansion hierarchy

18 operator families -> 794 lexemes -> 1,000 signatures -> parameter bindings -> ordered pairs -> ordered triples -> conditional macros -> newly discovered residual operators.

The 794-lexeme sweep importer consumes the exhaustive `lexeme_benchmark.csv` and refuses any source that does not contain exactly 794 records.

## Search

`frontier.py` preserves order for pairs/triples and prioritizes lexemes with unresolved contextual binding or review flags. Future selection should replace these structural priors with experimental EVSI as causal results accumulate.

## Promotion lifecycle

DISCOVERED -> DEFINED -> TYPED -> IMPLEMENTED -> EXECUTED -> MEASURED -> REPLICATED -> TRANSFERRED -> ROBUST

No later state is inferred from an earlier one.
