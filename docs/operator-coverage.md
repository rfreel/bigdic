# Coverage of the requested 38-operation workflow

The numbered workflow guides development; the toolkit does not claim to automate every operator semantically.

| Requested capability | Implemented boundary |
|---|---|
| Declare result, separate requirements/preferences | Bound objective, scope, target, actor, revision; source retains requirement distinctions |
| Check integrity, preserve basis | Exact source fingerprint; complete heading accounting; journal verification |
| Preserve alternatives and representations | Every indexed sense remains selectable; side-by-side comparison; nested lexical matches retained |
| Compose operations and inspect order | Explicit sequence ordering, source roles, inherited contracts, local refinements, role-handoff warnings |
| Execute and capture observations | User-authored toolkit edits are executed and journaled; described external operators are not executed |
| Update affected artifacts | Recompile the current instruction draft; preserve previous draft events |
| Branch, discriminate, specialize | Expose candidate senses for explicit selection; no automatic semantic discriminator is claimed |
| Verify and challenge | Executed source, parser, compiler, journal, and browser tests recorded separately |
| Preserve equivalence boundaries | No semantic merge or automatic optimal ordering is performed |
| Record supported status | Unbound/bound draft and NOT_EXECUTED are explicit; full instruction source is retained |

Out of scope: universal world catalogs, proof of continuation equivalence, empirical truth validation, external action execution, and automatic discovery of every missing meaning. These require application-specific models and evidence.
